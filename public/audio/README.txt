Audio guides by Gilbert Grimeau
================================

One folder per app language: en, de, fr, es.
Each folder holds up to five files with exactly these names (.m4a or .mp3):

  intro.m4a           Welcome. First screen (welcome questionnaire), then under "How it works"
  meditation-5.m4a    "Meditate 5 min" button
  meditation-10.m4a   "Meditate 10 min" button
  meditation-20.m4a   "Meditate 20 min" button
  farewell.m4a        Farewell and home practice. Day before departure and departure day

A file appears in the app as soon as it is in place (restart the app).
If a file is missing for a language, the app says the version is being
recorded and offers the languages that exist.

Sources (folder Webapp/Gilbert):
  EN: Introduction English / Meditation 5, 10, 20 Minutes English / Farewell and home practice English
  DE: Einführung Deutsch / Beginner German (= 5 min, 5:25) / Meditation 10, 20 Minuten Deutsch /
      Verabschiedung und Praxis Zuhause
